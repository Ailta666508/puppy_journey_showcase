# Puppy Journey 角色配音产品方案

## 1 功能定义

**先看一段有声的小语种情景视频，再由用户分别为黄狗和白狗录制台词，生成属于两个人的配音版本。**

AI 负责生成剧本、划分角色台词和提供示范声音；用户负责自己的角色录音。示范版始终保留，录错一句只重录这一句，不必重新生成整段视频。

首版沿用项目已有的西语对白和中文翻译。语言字段会预留扩展，但只有通过音色和发音验收的语言才进入选择列表，不把“小语种”写成已经支持所有语言。

## 2 为什么做

现在用户可以在未来排练室生成情景、剧本和视频，但没有完整的角色录音与成片功能。视频供应商即使返回声音，也不能保证与保存的剧本一致，更没有可直接替换某个角色的独立音轨。

这次要把观看变成一次可完成的练习：

- AI 先示范怎么说，用户不用从无声字幕猜读音。
- 黄狗和白狗各有明确的台词，打开页面就知道自己要录哪几句。
- 一个人可以先练，双方也可以异步接力，不必同时在线。
- 最后得到带真实用户声音的 MP4，而不只是网页里同时播放两段音频。

本次不做发音评分、声纹识别、声音克隆或实时通话，也不承诺人物口型与真人录音严格同步。

## 3 一次完整体验

以在咖啡店点单为例，以下台词仅为功能说明用的合成示例。

| 角色 | 西语台词 | 配音安排 |
| --- | --- | --- |
| 服务员 | ¿Qué desean tomar? | 保留 AI 示范 |
| 黄狗 | Un café, por favor. | 黄狗用户录制 |
| 白狗 | Para mí, un té. | 白狗用户录制 |

用户先观看有声示范，再进入“我来配音”。黄狗用户先完成自己的句子，生成一版“黄狗真人 + 白狗示范”的练习视频。之后白狗用户录完并确认，两人就可以合成“双人配音”版本。服务员始终使用独立保存的 AI 示范声音。

## 4 范围与交付

| 首版包含 | 首版不包含 |
| --- | --- |
| 有声示范视频及逐句示范播放 | 任意音视频文件上传 |
| AI 为黄狗、白狗分配适合练习的短句 | 语音克隆、模仿指定人物 |
| 按账号角色录音、试听、重录 | 自动发音打分、转写或纠正录音内容 |
| 单人练习与双人异步合成 | 实时连麦、两端同步录制 |
| 逐句保存、已提交进度恢复 | 保证未上传录音刷新后不丢 |
| 录音授权、取消任务、删除录音 | 无限制音频编辑、背景音乐制作 |
| 私有成片、版本历史、MP4 下载 | 精确口型同步、自动人声分离 |

交付要包含产品界面、服务端权限、私有录音存储、后台合成、恢复与测试。仅增加“录音”按钮或浏览器朗读不算完成。

## 5 AI 怎么分配台词

新剧本在生成时就标明稳定角色：黄狗、白狗或具体 NPC。根据情景把问候、表达需求、回应等短句分给两只小狗，避免一方只有一个语气词，另一方承担整段长对白。首版双人情景至少各有一句可练习台词；服务员等 NPC 负责引导，不强行分配给用户。

分工来自剧本语义，不根据声音、性别或昵称猜测账号身份。账号属于黄狗还是白狗，沿用情侣空间现有角色绑定。

生成预览中展示“黄狗录这几句 / 白狗录这几句 / 保留示范”。用户可在制作有声示范前通过“分配不对”调整。若角色缺失或矛盾，必须先确认，不能强行进入录音。

方案确认后固定台词、角色与版本。录音开始后改分工，应建立新方案并重新制作受影响的示范；旧录音不自动移到新角色或新句子，旧成片也不被覆盖。已有历史视频若分工不正确，提示重新创建排练，不声称修改声音就能修正画面中的角色。

## 6 页面和操作

### 6.1 有声示范

新建流程显示“生成有声排练视频”。现有历史视频需要先“制作有声示范”，明确这一步可能使用语音服务额度，不批量自动处理历史。

示范版的全部对白来自保存的剧本，黄狗、白狗与 NPC 使用可区分的通用声音。底层保留每句声音，而不是只保存一条混合音轨。

播放器提供“看示范”和“我来配音”。示范未准备完成时，展示真实阶段与失败重试；不能将无声测试视频标记为示范完成。

### 6.2 我的台词

桌面端左侧保留播放器，右侧是台词卡；手机端播放器在上、台词在下。沿用当前暖白、浅粉的页面，不再放复杂流程图。

每张台词卡显示：角色、西语、中文、可用录音时间、完成状态，以及“听示范 / 开始录音”。

自己的角色展开，对方角色折叠显示进度。NPC 标记为“AI 示范”。“我的声音”和“AI 示范”必须同时用文字区分，不能只靠颜色。

### 6.3 录一句

1. 点击“开始录音”后才申请麦克风；不申请摄像头。
2. 显示三秒视觉倒计时，停止示范声音，建议佩戴耳机。
3. 用户录制自己的这一句，页面显示计时和录音状态。
4. 停止后在本机试听，可重录、删除，或“保存这一句”。
5. 保存时才上传为仅本人可访问的草稿；界面明确区分“本机未保存”和“已保存”。

录音中切后台、锁屏或设备中断，显示“本次录音中断，请检查或重录”，不能直接显示成功。未保存的本机录音刷新后可能丢失；已上传且验证完成的草稿可以继续录。私人未提交草稿保存 7 天，保存后展示到期时间；已提交素材和正式成片不按草稿规则清理。

录音有声音不代表读对了台词。首版只检查可播放、时长、明显无声等基础质量，不给出发音正确率。

### 6.4 提交我的配音

所有本人练习句都要有明确选择：使用一条自己的录音，或主动选择“这句保留 AI 示范”。不能因漏录而悄悄混入 AI 声音。

点击“提交我的配音”时展示本次声音清单，并说明：

> 提交后，当前情侣空间的原参与者可以试听这些声音。合成前还会确认使用的录音版本；你的声音不会被用于音色克隆或发音评分。

只有自己可以提交、重录或删除自己的录音。伴侣不能代替确认。

### 6.5 单人或双人合成

| 模式 | 本人角色 | 对方角色 | 合成条件 |
| --- | --- | --- | --- |
| 我的练习版 | 本人选定的真人录音或明确保留的示范 | 全部 AI 示范 | 本人确认本次清单，至少含一句自己的录音 |
| 双人配音版 | 本人提交的选择 | 伴侣提交的选择 | 两人都确认同一份成片清单，且各有至少一句真人录音 |

双人版支持异步接力。等待时显示“你已准备好，等待对方确认”，不要求双方同时在线。若一方没有录好，可以明确改选单人练习，不冒充双人完成。

最终确认页列出每句采用谁的哪个录音版本。更换任何一句素材后，两人对旧清单的确认都不沿用，避免声音在不知情时被换掉。

### 6.6 成片

合成中可以离开页面，也可“取消合成”：停止当前任务，不删除已保存录音；之后再次合成仍须检查素材与确认是否有效。完成后显示“我的练习版”或“双人配音版”，支持切回示范、查看版本、播放及下载。

下载 MP4 自带声音，离线仍可播放。网页提供按台词窗口显示的双语字幕；字幕以保存剧本为准，不是对真人录音的转写。字幕也可单独下载为 WebVTT，首版不烧录到画面。

重录并再次合成形成新版本，不覆盖旧成片；重新录音不重新生成画面或整套示范声音。

## 7 台词时间与录音过长

首版采用固定的逐句窗口。窗口由实测示范音频加上练习余量形成，不直接沿用模型猜测的八秒时间戳。

用户录音较短时补静音；比窗口长时提示具体超出多少。用户主动停止、没有达到安全上限的完整录音，可以保存为仅本人可见的“待裁剪”草稿，试听后裁掉首尾空白或重录。仍超时的录音不能提交给伴侣或参与合成。

台词窗口是合成限制，不是强行截音的时间点。录制达到单句 10 秒安全上限时自动停止，并标记“可能未录完，需重录”，不接受这类片段进入成片。不能截词尾或自动加速人声。

示范方案定稿之前先核对总时长。现有画面生成目标约 8 秒，首版优先使用简短对话；少量超出时可经确认让最后画面停留，建议上限为 4 秒且不超过原片时长的 50%。超过范围则在录音开始前提示简化台词、重新生成，不把大量静止画面当成完整情景。

示范一旦确认，真人录音不能通过不断延长片尾挤入中间句子。需要更多朗读时间时应重新制作更宽松的练习方案，并告知相关录音需要重录。

## 8 权限和隐私

- **本机录音：**未点击保存前不上云，仅自己试听。
- **已保存草稿：**私有存储，仅录制者访问，伴侣只看到进度。
- **已提交录音：**允许原参与者试听；用于合成还需确认具体成片清单。
- **成片：**仅原参与者且仍在原情侣空间时可以申请播放和下载。
- **成员变化：**新加入的人不能自动继承前任参与者的真人声音；需要新建会话，不复制旧录音。

真人录音只用于媒体处理和成片，不默认发送给语音生成、转写或评分服务。AI 示范服务只接收必要台词，不接收完整情侣历史。

删除自己的录音时，列出受影响的待合成任务与成片；确认后停止它们的继续发布和新下载，后台清理文件。退出情侣空间后，账号中的“我的录音”仍允许本人撤回或删除自己的声音，但不恢复旧空间的播放或伴侣数据访问。该入口只显示本人的录音元数据和受影响结果数量。

无法远程撤回已经下载的副本；已签发链接及缓存也不承诺瞬时失效。

## 9 异常处理

| 情况 | 用户操作 |
| --- | --- |
| 拒绝麦克风、无设备或浏览器不支持 | 解释具体原因，仍可观看示范，不伪装录音成功 |
| 录音无声、损坏或超过窗口 | 指出对应句子，试听后重录；保留其他句 |
| 上传中断 | 保留本机录音并重试上传，不重新录制；刷新丢失前给提示 |
| 已提交后换了一句录音 | 创建新清单，重新请求参与者确认 |
| 合成失败 | 保留已确认录音，只重试合成 |
| 刷新或离开页面 | 恢复已保存进度与后台任务；不承诺恢复未上传声音 |
| 一方退出空间或撤回声音 | 停止使用相关真人声音，不自动换成 AI 后发布 |
| 原视频失效 | 不继续收费制作示范，提示重新生成原视频 |

## 10 验收标准

以下是开发验收目标，尚未实现或测试完成。

| 编号 | 场景 | 通过条件 |
| --- | --- | --- |
| P1 | 新建双人情景 | AI 给出黄狗、白狗及 NPC 的明确分工；两人均有适合练习的句子 |
| P2 | 有声示范 | 台词完整、顺序正确，每句可以单独试听 |
| P3 | 黄狗单人练习 | 只替换黄狗已选句，白狗和 NPC 示范保留；准确标记声音来源 |
| P4 | 双人异步完成 | 不同时在线也能提交，双方确认相同版本后才合成 |
| P5 | 重录其中一句 | 只替换该句，不重新生成整片，旧成片保留 |
| P6 | 超时、静音和中断 | 明确阻止无效录音进入成片，不截断词尾 |
| P7 | 成片与字幕 | 无重叠人声，跳转后字幕仍在正确窗口；不宣称逐词口型对齐 |
| P8 | 下载后断网 | MP4 可播放正确的人声，不依赖网页 API |
| P9 | 未提交及跨空间访问 | 伴侣看不到私人草稿；其他空间无法获取任何声音 |
| P10 | 确认后换素材 | 旧合成确认失效，不能悄悄替换 |
| P11 | 合成时删除或退出 | 迟到结果不会重新发布；新成员不能访问旧人声 |
| P12 | Chrome、Safari、手机 | 真机完成录音、试听、恢复、播放、下载流程 |

## 11 实施顺序与待确认项

建议按完整体验分五步推进：**有声示范与分角 → 逐句录音 → 双人提交与确认 → 后台合成与导出 → 恢复、安全及真机调优**。每步带相应测试，可以多次提交；功能走通前不在 README 中写成已上线。

请重点确认三个产品选择：

1. 首版先做西语，保留中文辅助；后续逐个增加经过试听验证的语言。
2. 支持“我的练习版”和“双人配音版”，各自录自己的角色，NPC 保留示范。
3. 首版采用逐句录制和固定窗口，不做一次性整片跟录或自动发音评分。

语音服务额度、私有存储和媒体 worker 的运行位置在开发时另行配置。当前仅形成两份评审文档，确认后再开始业务代码、数据库迁移与提交。
